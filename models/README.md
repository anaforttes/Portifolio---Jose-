# Pasta de Modelos 3D (SolidWorks -> Web)

Coloque aqui os arquivos **`.stl`** exportados do SolidWorks para exibição no portfólio.

## Como exportar do SolidWorks:
1. Abra a peça (`.SLDPRT`) ou montagem (`.SLDASM`) no SolidWorks.
2. Vá em **Arquivo > Salvar como... (File > Save As)**.
3. No tipo de arquivo, selecione **STL (`*.stl`)**.
4. (Opcional) Em *Opções*, marque **Binário** (gera arquivos menores e mais rápidos para carregar no site).
5. Salve nesta pasta `models/` ou teste diretamente arrastando para a aba **Laboratório 3D (STL)** do site.
